# UI 规范

> 目标是"同一类东西长得一样"。当前代码里还有不少 14dp、18dp 这种临时值，逐步收敛。

## 一、色板（`Ui.kt` 的 `Palette`）

| 变量 | 值 | 用途 |
|---|---|---|
| `accent` | `#4F46E5` | 主色，按钮、自己的气泡、链接 |
| `accentDark` | `#3730A3` | 主色深，图标徽章、强调文字 |
| `accentSoft` | `#EEF2FF` | 主色浅，chip 底色 |
| `bg` | `#F4F5FB` | 页面背景（冷灰紫，**不要用米色**） |
| `card` | `#FFFFFF` | 卡片、输入条 |
| `ink` | `#111827` | 标题、主要文字 |
| `body` | `#374151` | 正文 |
| `muted` | `#6B7280` | 次要文字 |
| `faint` | `#9CA3AF` | 时间、占位符 |
| `line` | `#E5E7EB` | 分割线、输入框描边 |
| `field` | `#F9FAFB` | 输入框底色 |
| `error` | `#B91C1C` | 错误、危险操作 |
| `ok` | `#047857` | 成功、已完成 |

网页端（`desktop/src/styles.css`）必须与上表一致，尤其 `bg` 用 `#f4f5fb`。

## 二、间距（**只用这 5 档**）

| 值 | 场景 |
|---|---|
| `4` | 图标与文字之间、紧凑元素 |
| `8` | 同组元素之间（标题与副标题） |
| `12` | 卡片内的段落间距 |
| `16` | 卡片内边距、页面左右边距、卡片之间 |
| `24` | 大区块分隔（section 上边距） |

分割线高度固定 `1`（px，不是 dp）。

> 现有代码里的 10 / 14 / 18 / 20 / 28 应当逐步归到这五档。

## 三、字号

| 字号 | 用途 |
|---|---|
| `11` | 时间戳、极小标签 |
| `12` | 次要说明、chip 文字 |
| `13` | 卡片描述、辅助信息 |
| `15` | 正文、气泡文字 |
| `16` | 卡片标题、列表主标题 |
| `21` | 页面级大标题（作业详情标题） |

## 四、圆角

| 值 | 用途 |
|---|---|
| `8` | 小元素（缩略图、小按钮） |
| `12` | 按钮、菜单行 |
| `16` | 卡片、气泡 |
| `999` | 胶囊（chip、状态标签） |

对话框统一 `22`（`res/drawable/dialog_round.xml`）。

## 五、组件约定

| 组件 | 规格 |
|---|---|
| 卡片 | 白底 + 16dp 圆角 + 2dp 阴影 + 16dp 内边距 |
| 圆形操作键 | 40dp（对话框内 32dp），线宽粗体，白底必须带 `line` 描边 |
| 底部输入条 | 一个圆角框内嵌两个圆，框内边距 6dp，多行时圆贴底 |
| 头像 | 列表 42-44dp，评论 36dp；优先 `face(name, avatar_path)`，无头像才回落首字 |
| 功能图标 | 统一用 `MenuGlyph` 线条风格，线宽 `size * 0.07`，圆角端点 |

## 六、图标清单（`MenuGlyph` 支持的 kind）

`work`（文档）`subject`（书签）`book`（打开的书）`bell`（铃铛）`people`（双人）`transfer`（双箭头）`logout`（默认）

**新增菜单项必须选一个语义不重复的图标**，不要复用 `work`——今晚三个菜单项撞车过一次。

## 七、文案约定

- 按钮用**动词**：`发布` / `加入班级` / `立即更新`，不要用 `确定` / `好的`
- 失败提示说**原因 + 怎么办**：「班里还有 2 位成员，不能解散」
- 危险操作确认框必须写清**后果**：「会删除本班的作业、评论和消息，不能恢复」
- 不用感叹号，不用"哦""啦"这类语气词
